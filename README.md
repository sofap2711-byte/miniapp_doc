# Dr. Volkova Aesthetics

Премиальный сайт-визитка для врача-косметолога.

## Структура

- `index.html` — главная страница
- `css/styles.css` — стили
- `js/main.js` — скрипты
- `images/` — фотографии

## Технологии

- HTML5
- CSS3 (CSS Variables, Flexbox, Grid, Backdrop-filter)
- Vanilla JavaScript
- Google Fonts (Cormorant Garamond, Inter)

## Запуск

Открой `index.html` в браузере или используй Live Server в VS Code.
